## 🛍️ Dev Store — Landing Page

Landing page de uma loja de tecnologia desenvolvida com foco em **design moderno, responsividade, animações e experiência do usuário**.

O projeto apresenta produtos de tecnologia através de uma interface interativa e visualmente moderna.

### ✨ Principais recursos

- 🎨 Interface moderna
- 📱 Layout responsivo
- 🛍️ Apresentação interativa de produtos
- 🔄 Navegação entre produtos
- ✨ Animações e transições em CSS
- ➜ Botão "Saiba Mais" animado
- ⚡ Interações utilizando JavaScript
- 🖼️ Destaque visual para cada produto
